# Idle Forge · 挂机锻造坊

Free single-file HTML5 idle clicker game. Strike the anvil to forge gold, hire
auto-smiths, upgrade your hammer, unlock critical strikes and an offline boiler,
and hit milestones to craft legendary gear — Iron Sword to Dragon Armor.

**Play:** https://shuangyueliao.github.io/idle-forge/

- Mouse / touch / keyboard (Space or Enter), procedural WebAudio sounds
- Offline progress (up to 2h) with a welcome-back panel, autosave every 5s
- Milestone system: 1K / 10K / 100K / 1M total forged unlocks new forge items
- Number formatting (1.23K/M/B), version-checked localStorage saves, mute button
- Procedural canvas visuals (breathing furnace glow, sparks, hammer animation),
  single HTML file, zero external assets, no dependencies
